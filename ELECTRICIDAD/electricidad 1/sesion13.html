Sesión 13: Ejercicios Prácticos de la Ley de Ohm

Aplicando los conceptos de la Ley de Ohm en situaciones reales

Objetivo Específico

Resolver problemas prácticos aplicando la Ley de Ohm, desarrollando la capacidad de analizar circuitos eléctricos simples y calcular voltaje, corriente y resistencia en diferentes configuraciones.

Repaso Rápido

V = I × R

Donde:

  • V = Voltaje (en voltios, V)
  • I = Corriente (en amperios, A)
  • R = Resistencia (en ohmios, Ω)

Recuerda que puedes reorganizar la fórmula según lo que necesites calcular:

  • Para calcular el voltaje: V = I × R
  • Para calcular la corriente: I = V / R
  • Para calcular la resistencia: R = V / I

Ejercicios Prácticos

Ejercicio 1: Cálculo de Corriente

Un circuito tiene una batería de 9V conectada a una resistencia de 3Ω. ¿Qué corriente circulará por el circuito?

Datos:

  • Voltaje (V) = 9V
  • Resistencia (R) = 3Ω
  • Corriente (I) = ?

Fórmula: I = V / R

Solución: I = 9V / 3Ω = 3A

Respuesta: Circularán 3 amperios por el circuito.

Ejercicio 2: Cálculo de Resistencia

Por un circuito circula una corriente de 0.5A cuando se le aplica un voltaje de 6V. ¿Cuál es el valor de la resistencia del circuito?

Datos:

  • Voltaje (V) = 6V
  • Corriente (I) = 0.5A
  • Resistencia (R) = ?

Fórmula: R = V / I

Solución: R = 6V / 0.5A = 12Ω

Respuesta: La resistencia del circuito es de 12 ohmios.

Ejercicio 3: Cálculo de Voltaje

Por una resistencia de 100Ω circula una corriente de 0.1A. ¿Qué voltaje hay entre sus extremos?

Datos:

  • Resistencia (R) = 100Ω
  • Corriente (I) = 0.1A
  • Voltaje (V) = ?

Fórmula: V = I × R

Solución: V = 0.1A × 100Ω = 10V

Respuesta: El voltaje entre los extremos de la resistencia es de 10 voltios.

Problemas Avanzados

Problema 1: Circuito en Serie

Un circuito tiene dos resistencias en serie: R₁ = 4Ω y R₂ = 6Ω. Si se conecta a una batería de 12V, calcula:

  1. La resistencia total del circuito
  2. La corriente que circula por el circuito
  3. La caída de voltaje en cada resistencia

1. Resistencia total (RT):

RT = R₁ + R₂ = 4Ω + 6Ω = 10Ω

2. Corriente total (I):

I = V / RT = 12V / 10Ω = 1.2A

3. Caída de voltaje en cada resistencia:

V₁ = I × R₁ = 1.2A × 4Ω = 4.8V

V₂ = I × R₂ = 1.2A × 6Ω = 7.2V

(Verificación: 4.8V + 7.2V = 12V ✓)

Problema 2: Potencia Eléctrica

Una plancha eléctrica tiene una resistencia de 24Ω y funciona con 120V. Calcula:

  1. La corriente que consume
  2. La potencia que disipa
  3. La energía consumida si está encendida durante 2 horas

1. Corriente (I):

I = V / R = 120V / 24Ω = 5A

2. Potencia (P):

P = V × I = 120V × 5A = 600W

o también: P = I² × R = (5A)² × 24Ω = 600W

3. Energía consumida en 2 horas:

E = P × t = 600W × 2h = 1200Wh = 1.2kWh

Resistencias en Paralelo

Cuando las resistencias se conectan en paralelo, el voltaje es el mismo en todas ellas, pero la corriente se divide entre las diferentes ramas. La resistencia total (RT) de resistencias en paralelo se calcula con:

1/RT = 1/R₁ + 1/R₂ + 1/R₃ + ...

O para dos resistencias en paralelo:

RT = (R₁ × R₂) / (R₁ + R₂)

Ejercicios de Resistencias en Paralelo

Ejercicio 4: Dos Resistencias en Paralelo

Se conectan dos resistencias en paralelo: R₁ = 4Ω y R₂ = 6Ω a una batería de 12V. Calcula:

  1. La resistencia equivalente del circuito
  2. La corriente total que suministra la batería
  3. La corriente que circula por cada resistencia
  4. La potencia disipada por cada resistencia

1. Resistencia equivalente (RT):

1/RT = 1/R₁ + 1/R₂ = 1/4Ω + 1/6Ω = 3/12 + 2/12 = 5/12

RT = 12/5 Ω = 2.4Ω

2. Corriente total (IT):

IT = V / RT = 12V / 2.4Ω = 5A

3. Corriente por cada resistencia:

I₁ = V / R₁ = 12V / 4Ω = 3A

I₂ = V / R₂ = 12V / 6Ω = 2A

(Verificación: I₁ + I₂ = 3A + 2A = 5A = IT ✓)

4. Potencia disipada:

P₁ = V × I₁ = 12V × 3A = 36W

P₂ = V × I₂ = 12V × 2A = 24W

PT = P₁ + P₂ = 36W + 24W = 60W

(Verificación: PT = V × IT = 12V × 5A = 60W ✓)

Ejercicio 5: Tres Resistencias en Paralelo

En el circuito mostrado en el diagrama, tenemos tres resistencias en paralelo: R₁ = 4Ω, R₂ = 6Ω y R₃ = 12Ω, conectadas a una batería de 12V. Calcula:

  1. La resistencia equivalente del circuito
  2. La corriente total que suministra la batería
  3. La corriente que circula por cada resistencia
  4. La potencia total del circuito

1. Resistencia equivalente (RT):

1/RT = 1/R₁ + 1/R₂ + 1/R₃ = 1/4Ω + 1/6Ω + 1/12Ω

1/RT = 3/12 + 2/12 + 1/12 = 6/12 = 1/2

RT = 2Ω

2. Corriente total (IT):

IT = V / RT = 12V / 2Ω = 6A

3. Corriente por cada resistencia:

I₁ = V / R₁ = 12V / 4Ω = 3A

I₂ = V / R₂ = 12V / 6Ω = 2A

I₃ = V / R₃ = 12V / 12Ω = 1A

(Verificación: I₁ + I₂ + I₃ = 3A + 2A + 1A = 6A = IT ✓)

4. Potencia total del circuito:

PT = V × IT = 12V × 6A = 72W

(Verificación: P₁ + P₂ + P₃ = (12V×3A) + (12V×2A) + (12V×1A) = 36W + 24W + 12W = 72W ✓)

Ejercicio 6: Resistencias Iguales en Paralelo

Se conectan cuatro resistencias de 100Ω en paralelo a una fuente de 10V. Calcula:

  1. La resistencia equivalente del circuito
  2. La corriente total del circuito
  3. La corriente que circula por cada resistencia
  4. ¿Qué sucede con la resistencia total si se añade una quinta resistencia igual en paralelo?

1. Resistencia equivalente (RT):

Para n resistencias iguales en paralelo: RT = R / n

RT = 100Ω / 4 = 25Ω

2. Corriente total (IT):

IT = V / RT = 10V / 25Ω = 0.4A

3. Corriente por cada resistencia:

I = V / R = 10V / 100Ω = 0.1A por cada resistencia

(Verificación: 4 × 0.1A = 0.4A = IT ✓)

4. Añadiendo una quinta resistencia:

RT-nueva = 100Ω / 5 = 20Ω

La resistencia total disminuye al añadir más resistencias en paralelo. En general, cuantas más resistencias se conectan en paralelo, menor es la resistencia total del circuito.
