🏗️ Proyecto Final: Instalación Eléctrica Completa

Descripción del Proyecto

Diseñar, instalar y documentar un sistema eléctrico completo para una habitación de 4m x 3m que incluya:

Especificaciones del proyecto:
  • Iluminación: 2 lámparas LED con control independiente
  • Tomas: 4 tomas de corriente con protección GFCI
  • Control: Sistema de conmutadores para iluminación
  • Protecciones: Disyuntores apropiados
  • Eficiencia: Optimización energética

Componentes Requeridos

  • Tablero de control con 6 circuitos
  • Cables de diferentes calibres
  • Interruptores y conmutadores
  • Tomas GFCI y estándar
  • Lámparas LED eficientes
  • Protecciones y disyuntores

Criterios de Evaluación

Criterio Peso Descripción
Diseño 25% Planos, cálculos, especificaciones
Instalación 30% Calidad técnica, cumplimiento normas
Seguridad 20% Protecciones, procedimientos
Eficiencia 15% Optimización energética
Documentación 10% Reportes, manuales, presentación

🛠️ Fases del Proyecto

Fase 1: Diseño y Planificación (1 hora)

Actividades:

  1. Análisis de necesidades: Definir requerimientos
  2. Cálculos eléctricos: Cargas, corrientes, protecciones
  3. Diseño de circuitos: Distribución y conexiones
  4. Selección de materiales: Lista detallada
  5. Planos técnicos: Diagramas unifilares

Fase 2: Instalación (1.5 horas)

Actividades:

  1. Preparación del sitio: Montaje de cajas
  2. Instalación de cables: Tendido y conexiones
  3. Montaje de dispositivos: Interruptores, tomas
  4. Configuración del tablero: Protecciones
  5. Verificaciones: Continuidad, aislamiento

Fase 3: Pruebas y Documentación (0.5 horas)

Actividades:

  1. Pruebas funcionales: Verificar funcionamiento
  2. Mediciones eléctricas: Voltajes, corrientes
  3. Verificación de seguridad: Protecciones
  4. Documentación final: Reportes y manuales
  5. Presentación: Exposición del proyecto
⚠️ CRÍTICO - Seguridad del Proyecto:
  • SIEMPRE seguir procedimientos LOTO
  • Verificar ausencia de tensión antes de trabajar
  • Usar EPP completo durante toda la instalación
  • Tener supervisión de instructor calificado
  • Documentar todas las verificaciones de seguridad

📄 Entregables del Proyecto

Documentación Técnica

  • Planos: Diagramas unifilares y de distribución
  • Cálculos: Cargas, corrientes, protecciones
  • Lista de materiales: Componentes y cantidades
  • Procedimientos: Instalación y pruebas
  • Especificaciones: Normas y estándares aplicados

Reportes de Instalación

  • Fotografías: Proceso de instalación
  • Mediciones: Valores eléctricos registrados
  • Pruebas realizadas: Resultados de verificaciones
  • Certificaciones: Cumplimiento de normas
  • Manual de usuario: Operación y mantenimiento

Presentación Final

  • Exposición oral: 10-15 minutos
  • Demostración práctica: Funcionamiento del sistema
  • Preguntas y respuestas: Defensa del proyecto
  • Evaluación de pares: Retroalimentación
