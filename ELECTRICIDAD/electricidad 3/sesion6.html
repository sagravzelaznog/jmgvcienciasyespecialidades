Contenido teórico

Dispositivos de protección avanzados

Disyuntores termomagnéticos

Protegen contra sobrecargas (térmico) y cortocircuitos (magnético). Se pueden resetear después de activarse.

[Símbolo disyuntor]

Interruptores Diferenciales

Detectan fugas de corriente a tierra, protegiendo contra descargas eléctricas.

[Símbolo diferencial]

Varistores (MOV)

Protegen contra sobretensiones transitorias, como las causadas por rayos.

[Símbolo varistor]

PTCs

Resistencias variables con la temperatura, usadas como fusibles auto-reseteables.

[Símbolo PTC]

Analogía práctica

Imagina el sistema de protección eléctrica como un equipo de bomberos:

  • Fusibles: Como extintores que se consumen al usarse

  • Diferenciales: Como detectores de humo que avisan de peligros ocultos
  • Varistores: Como pararrayos que desvían las amenazas

Estudio de caso: Análisis de falla

Situación: En una fábrica, los fusibles del área de producción se queman frecuentemente, causando paradas costosas.

Datos:

  • Fusibles de 30A
  • Corriente normal: 25A
  • Máquinas con motores de inducción
  • Variaciones de voltaje en la red

Preguntas para análisis:

  1. ¿Qué factores podrían estar causando los fusibles quemados?
  2. ¿Qué tipo de protección sería más adecuada para este caso?
  3. ¿Qué mediciones recomendarías realizar?

Pregunta de reflexión

¿Cómo cambiaría tu enfoque de protección si estuvieras diseñando un sistema para una instalación médica crítica versus una aplicación industrial? Considera factores como confiabilidad, velocidad de respuesta y mantenimiento.
